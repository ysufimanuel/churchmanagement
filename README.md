# Church Management — Android (Kotlin / Jetpack Compose)
Native parity app for the web CMS (`ysufimanuel/church-managements`). Requirements: `ANDROID_PARITY_IMPLEMENTATION.md`. Docs: `docs/`.
Setup: add to `~/.gradle/gradle.properties` `SUPABASE_URL`, `SUPABASE_ANON_KEY` (anon key only); run `gradle wrapper --gradle-version 8.9`, then `./gradlew assembleDebug`.
**Status: code written without a compiler; expect to fix build errors on first build.**
